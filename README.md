# Micalet Plymouth Theme

A minimal Plymouth splash for Micalet GNU/Linux. It has two independent image
assets: a static full-screen background and a logo with a very subtle opacity modulation.

## Animation

Only the logo changes opacity. It smoothly pulses between 35% and 100% opacity;
the background remains unchanged.
